# Skill Kit brand

## Platform

- **Name:** Skill Kit
- **External attribution:** Skill Kit by Gustavo Meilus
- **Promise:** Better defaults for coding agents.
- **Category:** Cross-agent working-method toolkit.
- **Problem:** Workflow drift—the working method a developer wants is lost between tasks, sessions, or hosts.
- **CTA:** Pick a skill. Install the method.

## Visual system

The identity uses a compact precision-bit metaphor: interchangeable modules held by a technical frame. It is intentionally abstract and avoids robot, brain, sparkle, magic, literal-toolbox, and vendor-logo imagery.

| Token | Value | Use |
| --- | --- | --- |
| Ink | `#11151B` | Primary dark background and text |
| Paper | `#F7F8FA` | Primary light background |
| Kit Cobalt | `#4B61E6` | Parent identity |
| Interface Blue | `#7183F3` | Secondary interface tone |
| Signal Mint | `#35C5A4` | Verification and active state |
| Signal Amber | `#E9AD3C` | Caution and release state |
| Signal Coral | `#E96B67` | Boundaries and exceptions |
| Slate | `#687180` | Secondary copy |

Use the parent frame consistently. Change only the internal glyph and restrained accent for a skill. The deterministic vector source assets are in [`assets/`](../assets/); raster derivatives should be exported from those files, never regenerated independently.

## Writing

Write directly, specifically, and with evidence. Prefer “runs the project’s normal verification command before completion” over quality claims. Avoid “AI-powered,” “10x,” “revolutionary,” “magic,” “battle-tested” without evidence, and AI-detector-evasion language.

The public display families are **BUILD**, **SHIP**, and **WRITE**. Technical slugs remain stable.
