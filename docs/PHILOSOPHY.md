# Skill Kit philosophy

Skill Kit turns recurring engineering judgment into reusable methods for coding agents.

1. Use the least powerful sufficient mechanism.
2. Let risk determine verification strength.
3. Use model judgment only where deterministic checks are insufficient.
4. Keep authority and context narrow.
5. Report evidence rather than implying success.
6. Add process only when it removes real uncertainty.

The collection is not a replacement coding agent, a prompt catalog, or a promise of universal software quality. Each plugin should solve one recurring job with explicit limits and the minimum necessary control surface.
